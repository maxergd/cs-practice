# Отчет по командам Git

## Различия между git log, git diff и git show:
* git log — показывает историю коммитов. С флагом --stat выводит краткую статистику измененных файлов и строк.
* git diff — показывает конкретную разницу в коде между коммитами или состояниями (в данном случае между HEAD~2 и HEAD).
* git show — показывает подробную информацию и изменения конкретного коммита (в данном случае предыдущего HEAD~1).

## Что нашли команды log -S и blame:
* git log -S"def" — ищет коммиты, в которых добавлялось или удалялось указанное слово (def). В нашем коде функций не было, поэтому ничего не найдено.
* git blame — построчно показывает файл calc.py с указанием автора и хэша коммита для каждой строки кода.
